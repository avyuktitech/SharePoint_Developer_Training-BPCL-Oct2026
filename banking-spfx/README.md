# Banking Experience (SPFx)

A responsive retail banking landing page web part for SharePoint. It includes a welcome hero, quick links, account snapshot cards, and a service notice. All figures are sample content and no customer data or banking APIs are connected.

## Run

Requires Node.js 22.14.x and a SharePoint Framework development environment.

```powershell
npm install
npm start
```

To package: `npm run build`. Use the SharePoint workbench to preview the web part.
