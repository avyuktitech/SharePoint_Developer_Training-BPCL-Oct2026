# BPCL Operations Pane (SPFx + React)

A compact, responsive operations dashboard web part inspired by petroleum and energy operations. It presents sample throughput, inventory, safety, and site status data with a selectable facility view. The sample does not connect to BPCL systems or represent live operational data.

## Run

Requires Node.js 22.14.x and a SharePoint Framework development environment.

```powershell
npm install
npm start
```

To package: `npm run build`. Use the SharePoint workbench to preview the web part.
