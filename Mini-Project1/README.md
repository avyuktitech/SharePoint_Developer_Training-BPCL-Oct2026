# SharePoint Framework mini-projects

Fourteen independent SPFx 1.23.2 samples:

| Project | Sample |
| --- | --- |
| `hello-spfx` | Starter Hello World web part generated by the SPFx Yeoman generator |
| `banking-spfx` | Responsive banking landing page for the fictional Horizon Bank |
| `bpcl-web-pane` | React-based BPCL-inspired operations dashboard with selectable facility and sample metrics |
| `tech-company-spfx` | React-based technology company homepage for the fictional Northstar Digital |
| `medical-spfx` | React-based hospital operations dashboard for the fictional CarePoint Health |
| `natural-gas-spfx` | React-based natural gas pipeline dashboard for the fictional Meridian Gas Network |
| `petroleum-retail-spfx` | React-based fuel station network dashboard for the fictional Apex Fuels Retail |

### Hands-on: PnPjs + Microsoft Graph

| Project | Sample |
| --- | --- |
| `pnp-task-tracker` | SharePoint list CRUD with `@pnp/sp` and a Microsoft Graph people picker |
| `pnp-employee-directory` | People search, profile photos and manager lookup with `@pnp/graph` |
| `pnp-my-workday` | Personal dashboard: Graph calendar, unread mail, recent files, plus site libraries via `@pnp/sp` |
| `pnp-leave-requests` | Leave approval workflow: SharePoint list with `@pnp/sp`, plus Graph manager lookup, email notifications and calendar events |

These four call Microsoft Graph, so after uploading the package a SharePoint admin must approve the requested permissions in **SharePoint admin center → Advanced → API access**. Each project's README lists the scopes.

### Hands-on: SharePoint extension + Power Automate

| Project | Sample |
| --- | --- |
| `spfx-approval-extension` | ListView Command Set that sends purchase requests to a Power Automate approval flow, with a step-by-step flow guide |

### Hands-on: Azure data services

| Project | Sample |
| --- | --- |
| `azure-blob-spfx` | Browse files, images and text from Azure Blob Storage using the signed-in user's Entra ID token |
| `azure-sql-spfx` | Browse tables, files and images from Azure SQL Database through a secured Azure Functions API |

Both start with built-in sample data. To connect them to Azure, follow the setup steps in each project's README.

Each project can be run independently from its folder:

```powershell
npm install
npm start
```

Use `npm run build` to package the SharePoint solution into `sharepoint/solution/*.sppkg`. All dashboards use demonstration content and do not connect to any financial, medical or operational systems.
