# Apex Fuels Retail (SPFx + React)

A responsive petroleum retail dashboard web part. A region selector switches the sample fuel sales, station availability, tank stock and payment figures, product demand chart, and network updates. Apex Fuels Retail is a fictional brand and no live station data is used.

## Run

Requires Node.js 22.14.x and a SharePoint Framework development environment.

```powershell
npm install
npm start
```

To package: `npm run build`. Use the SharePoint workbench to preview the web part.
