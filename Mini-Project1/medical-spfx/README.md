# CarePoint Health (SPFx + React)

A responsive hospital operations dashboard web part. A hospital selector switches the sample bed occupancy, ER wait time, surgery and staffing figures, department load chart, and care alerts. CarePoint Health is a fictional brand and no patient data is used.

## Run

Requires Node.js 22.14.x and a SharePoint Framework development environment.

```powershell
npm install
npm start
```

To package: `npm run build`. Use the SharePoint workbench to preview the web part.
