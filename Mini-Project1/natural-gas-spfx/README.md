# Meridian Gas Network (SPFx + React)

A responsive natural gas pipeline dashboard web part. A region selector switches the sample send-out, line pressure, storage and alarm figures, compressor station utilisation chart, and control room log. Meridian Gas Network is a fictional brand and no live network data is used.

## Run

Requires Node.js 22.14.x and a SharePoint Framework development environment.

```powershell
npm install
npm start
```

To package: `npm run build`. Use the SharePoint workbench to preview the web part.
