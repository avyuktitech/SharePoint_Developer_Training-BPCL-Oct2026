# SharePoint Framework mini-projects

Three independent SPFx 1.23.2 web part samples live beside `hello-spfx`:

| Project | Sample |
| --- | --- |
| `banking-spfx` | Responsive banking landing page with sample account and service content |
| `bpcl-web-pane` | React-based BPCL-inspired operations dashboard with selectable facility and sample metrics |
| `tech-company-spfx` | React-based technology company homepage for the fictional Northstar Digital |

Each project can be run independently from its folder:

```powershell
npm install
npm start
```

Use `npm run build` to package the SharePoint solution. The banking and BPCL dashboards use demonstration content and do not connect to financial or operational systems.
