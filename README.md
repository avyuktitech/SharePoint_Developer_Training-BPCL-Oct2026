# SharePoint Framework mini-projects

Seven independent SPFx 1.23.2 web part samples:

| Project | Sample |
| --- | --- |
| `hello-spfx` | Starter Hello World web part generated by the SPFx Yeoman generator |
| `banking-spfx` | Responsive banking landing page for the fictional Horizon Bank |
| `bpcl-web-pane` | React-based BPCL-inspired operations dashboard with selectable facility and sample metrics |
| `tech-company-spfx` | React-based technology company homepage for the fictional Northstar Digital |
| `medical-spfx` | React-based hospital operations dashboard for the fictional CarePoint Health |
| `natural-gas-spfx` | React-based natural gas pipeline dashboard for the fictional Meridian Gas Network |
| `petroleum-retail-spfx` | React-based fuel station network dashboard for the fictional Apex Fuels Retail |

Each project can be run independently from its folder:

```powershell
npm install
npm start
```

Use `npm run build` to package the SharePoint solution into `sharepoint/solution/*.sppkg`. All dashboards use demonstration content and do not connect to any financial, medical or operational systems.
