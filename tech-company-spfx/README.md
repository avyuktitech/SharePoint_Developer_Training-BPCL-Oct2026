# Northstar Digital (SPFx + React)

A responsive technology company homepage web part featuring a services hero, capability cards, project metrics, and a contact call to action. Northstar Digital is a fictional sample brand.

## Run

Requires Node.js 22.14.x and a SharePoint Framework development environment.

```powershell
npm install
npm start
```

To package: `npm run build`. Use the SharePoint workbench to preview the web part.
